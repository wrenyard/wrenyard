# @wrenyard/runtime-win32-x64

This is an unpublished placeholder package.

When built by the release pipeline, this package will contain:

- the prebuilt Forge binary for win32-x64 (under `bin/`), and
- a checksum-bearing `runtime-manifest.json` describing that artifact.

It intentionally contains no binary and is not publishable today. The package
contract is reserved so that release-built platform packages can fill it in
later.
